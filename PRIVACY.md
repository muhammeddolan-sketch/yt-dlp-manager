# Privacy Policy for UniGet Web Helper

UniGet Web Helper ("the Extension") is designed to facilitate media downloads from web pages to the UniGet desktop application.

## 1. Data Collection
The Extension **does not collect, store, or transmit any personal data**. It only processes the URLs of media files found on web pages that the user explicitly interacts with.

## 2. Data Usage
The media URLs identified by the Extension are sent locally to the UniGet desktop application running on the user's computer. No data is sent to external servers or third parties.

## 3. Permissions
- **activeTab / tabs**: Used to identify media on the current page.
- **scripting**: Used to extract media links.
- **storage**: Used to save local settings (e.g., language).
- **notifications**: Used to notify the user about download status.

## 4. Contact
For any questions regarding this policy, please contact the repository owner on GitHub.
